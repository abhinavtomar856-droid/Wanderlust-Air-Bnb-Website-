# Wanderlust

An Airbnb-style web app where users can view, create, edit and delete property listings.

## Tech Stack

- Node.js
- Express.js
- MongoDB with Mongoose
- EJS and ejs-mate
- Bootstrap

## Features

- View all listings
- Add a new listing
- Edit and update a listing
- Delete a listing

## Run Locally

1. Clone the repo
   git clone https://github.com/YOUR_USERNAME/wanderlust.git
2. Go to the folder
   cd wanderlust
3. Install packages
   npm install
4. Start MongoDB, then run
   node app.js
5. Open http://localhost:8080/listings
